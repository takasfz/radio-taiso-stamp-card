# ラジオ体操 出席カード

夏休みの朝、ラジオ体操に行くとカードにハンコを押してもらえた——あの出席カードをブラウザで再現したものです。バックエンドなし・静的ファイルのみで動きます。

## あそびかた

- 7月・8月のカレンダーの「きょう」のマスをタップすると、ハンコが「ポンッ!」と押されます(1日1回)
- ハンコは 3 種類(たいよう・ひまわり・ほし)からランダム
- スタンプの数と連続日数が下に表示されます
- 記録はブラウザの `localStorage` に保存されます(サーバーには何も送りません)
- 「カードを あたらしくする」でリセットできます

## GitHub Pages での公開

1. リポジトリの **Settings → Pages** を開く
2. **Source: Deploy from a branch** を選び、公開したいブランチ(例: `main`)と `/ (root)` を指定
3. 数分後に `https://<ユーザー名>.github.io/radio-taiso-stamp-card/` で公開されます

ビルド工程はありません。`index.html` / `style.css` / `app.js` の 3 ファイルだけで動きます。

## キャラクターについて

カードのキャラクターやハンコの絵柄は、このリポジトリのために描き下ろしたオリジナルの SVG です(既存キャラクターの画像・データは使用していません)。
